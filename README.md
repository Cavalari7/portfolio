# Portfólio — Igor Cavalari

Site estático (HTML, CSS e JavaScript puros, sem dependências).

```
index.html                     Página completa
assets/css/style.css           Estilos e design system (variáveis no topo)
assets/js/main.js              Interações e animações
assets/img/                    Foto, logo, capas dos projetos e imagem de compartilhamento
Curriculo-Igor-Cavalari.pdf    Currículo (botões Visualizar e Baixar)
favicon.svg                    Ícone do site
```

## Publicar no GitHub Pages
Envie todo o conteúdo desta pasta para a raiz do repositório `portfolio` e mantenha o GitHub Pages ativo na branch principal.

## Editar
- Textos, projetos e links: `index.html`.
- Cores e fontes: variáveis no início de `assets/css/style.css`.
- Formulário: envia pelo Formspree (`https://formspree.io/f/xljbjene`); se falhar, abre o e-mail do visitante.
